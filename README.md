# 👋 Workshop de Git y GitHub — Cubo AI

Es una página web sencilla que sirve para practicar el flujo básico de trabajo con Git y GitHub.

## 📌 Descripción

Una página HTML que muestra el mensaje **"hello worl!"** junto a una imagen de bienvenida.

## 🎯 Objetivos de aprendizaje

- Crear un repositorio en GitHub
- Inicializar y clonar repositorios con Git
- Hacer commits y entender el historial de cambios
- Subir cambios al repositorio remoto (`git push`)
- Publicar un proyecto web simple

## 📁 Estructura del repositorio

```
├── index.html     # Página web con el mensaje y la imagen de bienvenida
└── [imagen.ext]   # Imagen de bienvenida mostrada en la página
```

## 🛠️ Tecnologías

- HTML
- Git
- GitHub

## ▶️ Cómo ver el proyecto

1. Clona el repositorio:
   ```bash
   git clone [URL-del-repositorio]
   ```
2. Abre `index.html` en tu navegador.
